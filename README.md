# ArchiDesign

![ArchiDesign](./img/preview.png)

## Sobre o projeto

O **ArchiDesign** foi o meu **primeiro projeto de site desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas no SENAI**.

O projeto foi criado como uma experiência prática para aplicar os conhecimentos adquiridos durante o curso, principalmente na construção de páginas web, organização de conteúdo e desenvolvimento de uma interface simples e funcional.

A proposta do site é apresentar uma empresa fictícia relacionada à **arquitetura e design**, com uma identidade visual voltada para o setor de construção e arquitetura.

## Funcionalidades

- Página inicial com apresentação do site
- Seção "Sobre"
- Seção de projetos
- Área de contato
- Navegação entre as páginas/seções
- Layout responsivo e organizado
- Interface com foco em arquitetura e design

## Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

## Objetivo

Mais do que o resultado visual, este projeto representa um dos primeiros passos da minha trajetória no desenvolvimento web. Foi através dele que comecei a colocar em prática conceitos de **estruturação de páginas, estilização, navegação e organização de um projeto web**.

Com o tempo, continuei estudando e desenvolvendo projetos mais complexos, mas o ArchiDesign permanece como um registro importante do início da minha jornada na programação.
